## Overview

Arma Combat Manager is an external companion for Arma Reforger group play, reading game state from the local game client to display real-time team member positions on a tactical map overlay, track squad ammunition and casualty status, log radio frequencies and mission parameters, and support ORBAT planning for organized milsim groups.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Arma Combat Manager** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Tactical Map** | Real-time squad member position display on a tactical map overlay |
| **Casualty Tracker** | Tracks squad member status — active, wounded, or KIA — in real time |
| **Ammo Status** | Aggregated ammunition count per squad member for resupply planning |
| **ORBAT Planning** | Drag-and-drop order of battle planner for pre-mission briefings |
